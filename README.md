# Gestión de clase

App para llevar el día a día del aula:

- **Alumnos**: alta de alumnos por grupo, con ficha individual.
- **Cono**: actividades, controles y proyectos.
- **Lengua**: actividades, controles y proyectos, más lecturas y velocidad lectora (con gráfica de evolución).
- **Comportamiento y material**: incidencias con puntos, y registro de material olvidado.
- **Panel**: resumen del día (material que falta, incidencias, próximos controles).

Los datos se guardan en el navegador (localStorage), no hay backend.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
